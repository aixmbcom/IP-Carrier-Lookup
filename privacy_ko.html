🔒 개인정보처리방침

귀하의 개인정보를 소중히 보호합니다

최종 업데이트: 2026년 1월

📋 개요

IP 지리 위치 조회 도구를 이용해 주셔서 감사합니다. 당사는 개인의 프라이버시의 중요성을 이해하고 이를 보호하기 위해 최선을 다하고 있습니다. 본 개인정보처리방침은 당사가 귀하의 정보를 어떻게 수집, 사용, 보호하는지 설명합니다.

📊 수집하는 정보

수집하는 정보:

  • IP 주소: 서비스를 이용하여 IP를 조회할 때 입력한 IP 주소는 결과를 제공하기 위해 일시적으로 처리됩니다.
  • 방문자 IP: "내 IP 주소"를 클릭하면 현재 공인 IP를 얻어 조회 서비스를 제공합니다.
  • 기술 정보: 서비스 품질 향상을 위해 브라우저 유형, OS, 접속 시간 등의 기본 기술 정보를 수집할 수 있습니다.

🎯 정보 사용 목적

수집된 정보는 다음 목적으로 사용됩니다:

  • IP 지리 위치 조회 서비스 제공
  • 사용자 경험 개선 및 최적화
  • 서비스 사용 분석 및 품질 향상
  • 웹사이트 보안 유지 및 오남용 방지

🔐 정보 보호

당사는 귀하의 정보를 보호하기 위해 다음 조치를 취하고 있습니다:

  • 모든 조회는 암호화된 HTTPS를 통해 전송됩니다
  • 조회된 IP 주소를 영구적으로 저장하지 않습니다
  • 조회 기록은 일시적인 처리에만 사용됩니다
  • 업계 표준 보안 조치를 채택하고 있습니다

🌐 제3자 서비스

본 도구는 IP 위치 데이터를 제공하기 위해 제3자 API 서비스(IPinfo.io)를 사용합니다. 서비스를 이용할 때:

  • 조회 요청은 제3자 API 서버로 전송됩니다
  • 제3자 제공업체는 자체 개인정보처리방침을 가질 수 있습니다
  • IPinfo.io의 개인정보처리방침을 검토하시기 바랍니다

🍪 쿠키 및 추적

당사 웹사이트에서는 다음 기술을 사용할 수 있습니다:

  • 로컬 스토리지: 사용자 설정 및 조회 기록을 일시적으로 저장(브라우저 내에만)
  • 분석 도구: Google Analytics 등을 사용하여 사이트 트래픽 분석
  • 광고 서비스: Google AdSense 등의 제3자 광고 서비스 사용
  • 브라우저 설정에서 이러한 기능을 관리하거나 비활성화할 수 있습니다

👤 사용자 권리

귀하는 다음의 권리를 가지고 있습니다:

  • 언제든지 서비스 사용 중단
  • 브라우저의 로컬 스토리지 데이터 삭제
  • 정보 사용 방법에 대해 알 권리
  • 보유된 개인정보 삭제 요청
